# Admin Dashboard
This is a project done during the curse "Intermediate HTML and CSS" in The Odin Project. The initial specifications were [this image](https://raw.githubusercontent.com/TheOdinProject/curriculum/43cc6ab69fdfbef40d431a65677d2144668930ac/intermediate_html_css/grid/project_admin_dashboard/imgs/dashboard-project.png) and this is the final result website: https://claracanyis.github.io/admin-dashboard

This website has been done only with Grid layout as asked in the specifications. There are several layouts within the page that would have been done with Flexbox otherwise.
